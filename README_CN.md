# Zhongzi

启动你的 Phoenix 服务器：

  * 运行 `mix setup` 来安装和设置依赖项
  * 使用 `mix phx.server` 启动 Phoenix 端点，或在 IEx 中使用 `iex -S mix phx.server`

现在你可以在浏览器中访问 [`localhost:4000`](http://localhost:4000)。

准备在生产环境中运行？请[查看我们的部署指南](https://hexdocs.pm/phoenix/deployment.html)。
